# Shipment Tracker - Full Stack (Real-Time)

A full stack web application for tracking shipments in real time using WebSockets.

This project demonstrates real-time communication between frontend and backend using WebSocket technology, in addition to standard REST APIs.


## Tech Stack

### Backend
- Java
- Spring Boot
- Spring WebSocket
- Spring Data JPA
- RESTful APIs

### Frontend
- Angular
- TypeScript
- WebSocket (STOMP / SockJS)
- Bootstrap


## Key Features

- Create new shipment
- Update shipment status
- Track current location
- Real-time updates using WebSockets
- No page refresh required
- REST API + WebSocket integration


## Real-Time Functionality

This project uses WebSockets to push live updates from the backend to all connected clients.

### Example:
- When one user updates a shipment status,
- All other users see the update instantly without refreshing the page.
